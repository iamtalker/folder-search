# 폴더검색 (Folder Search)

브라우저에서 로컬 폴더를 골라 그 안의 파일들을 (이름 + 내용까지) 검색하는 단일 HTML 파일 도구입니다.
서버나 설치 없이, 이 저장소의 `폴더검색.html` 파일 하나만 다운로드해서 브라우저로 열면 바로 씁니다.

세 가지 형태가 있습니다: **웹 버전**(`폴더검색.html` 하나) / **데스크톱 exe**(`FolderSearch.exe` + `폴더검색.html`, 같은 폴더에 두고 실행 — 파이썬 설치 불필요, [Releases](../../releases)에서 다운로드) / **데스크톱 파이썬 버전**(`desktop/` 폴더, 직접 실행/개발용).

## 요구사항

- **웹 버전**: Chrome 또는 Edge (File System Access API를 사용합니다. Firefox/Safari는 아직 미지원)
- **데스크톱 exe**: Windows + WebView2 런타임(보통 이미 있음). 그 외 아무것도 설치할 필요 없음(단, `FolderSearch.exe`와 `폴더검색.html`이 같은 폴더에 있어야 함).
- **데스크톱 파이썬 버전**: Python 3 + `pip install -r desktop/requirements.txt` (Windows, WebView2 런타임 필요)

## 기능

- 📁 폴더 선택 후 하위 폴더까지 재귀적으로 스캔
- 검색어와 파일명/본문 일치 정도로 **관련도순** 정렬, **최신순** 정렬도 지원 (정렬 버튼을 한 번 더 누르면 반대 방향)
- `AND` / `OR` / `NOT` + 괄호를 쓰는 불리언 검색 (`"정확한 구절"` 검색도 가능)
- 📅 수정일 기간 필터 (`2021.01.01`처럼 직접 입력, 시작일·종료일 중 하나만 써도 됨)
- 결과 페이지 나눠 보기, 페이지당 표시 개수(20/50/100/200/500) 선택
- 한 번 읽은 폴더는 캐시해두고, 다시 열 때 바뀌거나 새로 생긴 파일만 다시 읽음 (데스크톱 버전은 앱을 껐다 켜도 유지)
- 🔄 새로고침 버튼으로 폴더를 처음부터 다시 읽기
- 최근 사용한 폴더 여러 개를 기억해뒀다가 클릭 한 번으로 전환 (브라우저의 IndexedDB에 저장, 서버로 전송되는 데이터 없음)
- 권한 없는 시스템 폴더(`System Volume Information` 등)는 자동으로 건너뜀
- 대상 확장자 / 제외 폴더 이름을 직접 편집 가능

## 사용법

**웹 버전**: `폴더검색.html`을 다운로드해서 더블클릭으로 엽니다 (Chrome/Edge).

**데스크톱 exe**: [Releases](../../releases)에서 `FolderSearch.exe`와 `폴더검색.html`을 둘 다 다운로드해서 같은 폴더에 넣고 `FolderSearch.exe`를 실행합니다.

**데스크톱 파이썬 버전(소스로 실행)**: 저장소 전체(`폴더검색.html` + `desktop/`)를 받아서 `pip install -r desktop/requirements.txt` 후 루트의 `run.bat` 실행 (또는 `python desktop/main.py`).

1. "📁 폴더 선택"을 눌러 검색할 폴더를 고릅니다.
2. 검색창에 검색어를 입력합니다. 공백은 AND로 동작하고, `OR`/`NOT`과 괄호도 쓸 수 있습니다.
3. 폴더 내용이 바뀌었다면 "🔄 새로고침"을 눌러 다시 읽습니다.

### 웹 버전 vs 데스크톱 버전

**데스크톱 버전을 만든 이유가 바로 이겁니다**: 웹 버전은 브라우저(File System Access API) 보안 정책상 "문서/바탕화면/다운로드" 같은 몇몇 폴더를 아예 선택하지 못하게 막혀있습니다. 데스크톱 버전은 OS의 파일 선택창을 그대로 쓰기 때문에 이 제한이 없어서, 막혀있는 폴더까지 검색하고 싶을 때 씁니다.

## 왜 만들었나

모든 파일을 브라우저 메모리로 읽어 들여 검색하는 방식이라, 파일 몇천~몇만 개 수준의 폴더에서 **파일 내용까지** 찾고 싶을 때 적합합니다.
파일 *이름*만 찾고 싶고 드라이브 전체처럼 훨씬 큰 규모라면, [Everything](https://www.voidtools.com/) 같은 네이티브 파일 인덱서가 더 적합합니다.

## exe 빌드 방법

`desktop/build_exe.bat` 실행 (PyInstaller 사용). 결과물은 `desktop/dist/FolderSearch.exe` + `desktop/dist/폴더검색.html`(같은 폴더에 자동으로 복사됨) — 이 두 파일은 항상 같이 다녀야 합니다.

## 개인정보

모든 처리는 브라우저 안에서만 이루어집니다. 파일 내용이나 폴더 경로가 어디로도 전송되지 않습니다.

## 변경 이력

각 버전의 자세한 설명(한/영)은 [Releases](../../releases)에 있습니다.

- **2.6.4** — 관련도 점수를 "등장 횟수 합계"에서 "본문 길이당 등장 밀도"로 변경. 수십만 자짜리 큰 파일이 흔한 단어를 우연히 많이 포함했다는 이유만으로, 검색어와 딱 맞는 짧은 글보다 위로 올라오던 문제 수정. 파일명 일치 보너스는 그대로.
- **2.6.3** — 웹 버전 세션 캐시를 최근 3개 폴더로 제한(2.6.2 이후 여러 폴더를 돌아다니면 전부 메모리에 쌓이던 문제). 검색 결과 스니펫을 만들 때 본문을 매번 다시 소문자 변환하던 중복 연산 제거.
- **2.6.2** — 웹 버전에서 폴더 A → B → 다시 A로 전환하면, 화면엔 "폴더: A"라고 뜨면서 실제로는 B 폴더 내용이 검색되던 버그 수정. 세션 캐시가 파일 개수만 저장하고 문서 목록은 저장하지 않았던 게 원인. (데스크톱 버전은 영향 없음)
- **2.6.1** — 웹 버전에서 키 입력마다 모든 문서의 `파일명+내용`을 새로 소문자 변환하던 것을, 스캔 시 한 번만 만들어두고 재사용하도록 개선. 큰 폴더에서 타이핑 지연 감소.
- **2.6.0** — 캐시가 파일 변경을 감지. 폴더를 다시 열면 수정시각/크기를 비교해서 바뀌거나 새로 생긴 파일만 다시 읽고, 지운 파일은 자동으로 빠짐. `(NOT 단어)`처럼 닫는 괄호가 단어에 붙어있으면 그룹이 안 닫히던 검색어 파싱 버그도 수정.
- **2.5.0** — exe가 `폴더검색.html`을 내부에 내장하던 방식에서, exe 옆에 실제 html 파일을 두는 방식으로 변경(무엇이 실행되는지 그대로 보이도록). `FolderSearch-exe.zip`으로 둘을 함께 배포.
- **2.4.0** — 파이썬 설치 없이 실행되는 독립 exe(`FolderSearch.exe`) 추가. 데이터는 `%LOCALAPPDATA%\FolderSearch`에 저장.
- **2.3.1** — 날짜 필터 라벨을 "검색일 기간"으로 변경, 종료일 예시 문구를 오늘 날짜로 표시.
- **2.3.0** — 정렬 버튼을 한 번 더 누르면 반대 방향 정렬(최신순 ↔ 오래된순 등). 200개에서 잘리던 결과를 페이지네이션으로 전부 볼 수 있게 됨. 페이지당 개수(20/50/100/200/500) 선택 가능.
- **2.2.0** — 검색창 아래에 수정일 기간 필터 추가. `2021.01.01`처럼 직접 입력(`.`/`-`/`/` 구분자 모두 지원), 시작일·종료일 중 하나만 써도 됨.
- **2.1.0** — "N개 파일 인덱싱됨" 표시를 진행바 바로 아래로 이동.
- **2.0.1** — 대상 확장자 / 제외 폴더 기본값을 빈 칸으로 변경(기본적으로 모든 파일 검색).
- **2.0.0** — 데스크톱 버전의 검색을 파이썬 쪽으로 이전. 스캔할 때마다 파일 내용 전체(8천여 개 기준 약 219MB)를 JS로 넘기던 게 속도 차이의 진짜 원인이었음. 이제 결과 목록만 주고받아서 웹 버전 수준으로 빨라짐.
- **1.6.2** — 1.6.1에서 추가한 캐시/소요 시간 표시가 곧바로 검색 결과 상태줄에 덮어써지던 버그 수정.
- **1.6.1** — 상태줄에 캐시 사용 여부와 소요 시간 표시(캐시를 안 쓴 경우 그 이유도 함께).
- **1.6.0** — 데스크톱 버전: 한 번 읽은 폴더를 디스크 캐시에 저장해서 앱을 껐다 켜도 다시 읽지 않음(8,235개 파일 기준 1.82초 → 0.47초).
- **1.5.0** — 데스크톱 스캔 속도 개선: 파일 읽기 스레드풀 병렬화, 파이썬↔JS 왕복 횟수 412번 → 42번으로 감소.
- **1.4.0** — 이번 세션에서 이미 읽은 폴더로 돌아가면 디스크를 다시 읽지 않고 메모리 결과 재사용.
- **1.3.0** — 데스크톱 버전에서 스캔이 끝난 뒤에도 검색이 바로 안 되던 지연 수정(결과를 40개씩 나눠서 바로바로 전달). `run.bat`을 저장소 루트로 이동.
- **1.2.0** — 웹/데스크톱 버전이 `폴더검색.html` 하나를 공유하도록 통합(실행 환경을 자동 감지해서 폴더 접근 방식만 교체). 데스크톱 창 닫을 때 오래 걸리던 문제 수정.
- **1.1.0** — 데스크톱 버전(파이썬 + pywebview) 추가. 웹 버전에서 막혀있던 문서/바탕화면/다운로드 폴더도 검색 가능.
- **1.0.0** — 첫 릴리스. 폴더 재귀 스캔, 파일명+내용 검색, 관련도순/최신순 정렬, `AND`/`OR`/`NOT`/괄호/구절 검색, 최근 폴더 기억.
